# SignalLens 投資組合風險與新聞情緒整合系統規格書

版本：3.0  
狀態：面試／GitHub 展示版實作基準

## 1. 整合目的

本規格合併「投資組合風險分析系統」與「AI 新聞情緒分析系統」。系統不只是把兩套畫面放進同一個選單，而是以同一份投資組合為資料主體，依序完成：

1. 使用者風險承受能力評估。
2. 投資組合配置與歷史價格風險計算。
3. 對各股票持倉取得新聞情緒資料。
4. 將價格風險與新聞情緒維持為兩個獨立維度，再進行並列解讀。
5. 產生一份整合 AI 研究報告與 PDF。

系統僅供教育與研究，不產生買賣訊號、目標價或報酬預測。

## 2. 衝突處理決策

| 原規格差異 | 統一決策 |
|---|---|
| 風險系統使用 Perplexity；情緒系統使用 OpenAI | 建立 AI Provider 層；投資組合可用 Perplexity，新聞與整合報告優先使用 OpenAI `gpt-5-mini`，未設定 OpenAI 時可由 Perplexity 執行 |
| FMP 與 Alpha Vantage 都提供價格 | 組合風險以 FMP 歷史資料為準；新聞頁 K 線以 Alpha Vantage TIME_SERIES_DAILY 為準，失敗時可顯示 FMP 備援資料並標示來源 |
| 原規格要求在 UI 輸入 API Key | 部署版改為伺服器端環境變數或 Streamlit secrets，不在瀏覽器輸入或回傳 Key |
| 原規格要求單一 Python 檔 | 面試版採模組化架構、測試與 CI；功能需求不因拆檔而改變 |
| 情緒可能被誤當成風險分數 | 不把 `[-1, 1]` 情緒分數加到 `[0, 100]` 風險分數，只建立二維狀態與文字解讀 |

## 3. 系統流程

`風險屬性 → 投資組合配置 → 價格風險分析 → 多持倉新聞分析 → 整合判讀 → PDF/CSV 匯出`

所有階段共用 `st.session_state`。使用者可在專業頁面深入查看風險、新聞、ETF 與產品警示，但「整合分析」是主要入口。

## 4. 功能需求

### U-001 使用者與投資組合

- 五種風險屬性、四項風險構成分數、可投資資金。
- 動態新增／刪除股票及現金配置。
- 股票代碼正規化、重複檢查、總配置必須為 100%。
- 配置圓餅圖與即時驗證。

### U-002 投資組合價格風險

- FMP 歷史收盤價、公司名稱、產業與選配 Beta。
- 年化報酬、年化波動率、最大回撤、Beta 風險。
- 原規格可追溯風險分數：波動率 70%＋Beta 30%。
- 另提供共變異數組合波動率、歷史 VaR/CVaR、HHI、有效持倉數及成分風險貢獻。
- 現金不計入市場風險。

### U-003 新聞與價格情緒研究

- Alpha Vantage NEWS_SENTIMENT，新聞數量 1–200。
- Alpha Vantage TIME_SERIES_DAILY K 線，顯示最近 30 個交易日；計算 MA5、MA10、MA20、MA60。
- 分別統計 ticker sentiment 與 overall sentiment 五級分布。
- 顯示平均 ticker 情緒、文章情緒、相關性與主要情緒。
- 來源分布、主題加權分布、每日情緒趨勢。
- 前 10 則高相關新聞須顯示時間、兩種情緒、相關性、前三主題、摘要及原文連結。
- 將每日情緒與下一交易日報酬對齊；資料足夠時顯示相關係數，並明確聲明不代表因果。
- 提供離線合成資料模式，確保面試展示不依賴 API。

### U-004 多持倉整合分析

- 以非現金持倉為分析清單，可設定每檔新聞數量。
- 依配置比例計算「組合新聞情緒摘要」，但保留每檔樣本數與資料來源。
- 同時顯示：組合風險分數、組合波動率、集中度、加權新聞情緒與新聞覆蓋率。
- 不把新聞情緒轉換為買賣分數。
- 整合 AI 報告章節：
  1. 執行摘要
  2. 價格風險與集中度
  3. 各持倉新聞情緒
  4. 價格與情緒並列觀察
  5. 風險適配性與教育要點
  6. 資料限制與免責聲明

### U-005 AI Provider

- OpenAI 使用 Responses API 與 `gpt-5-mini`。
- Perplexity 使用現行 `sonar` 系列端點。
- Provider 必須具備逾時、認證、用量限制、格式錯誤與安全訊息處理。
- 新聞標題和摘要一律視為不可信資料，以明確 delimiter 包裝並忽略其中指令。
- Prompt 僅傳送完成分析所需資料，限制新聞篇數與摘要長度。

### U-006 報告

- PDF 同時包含風險屬性、資產風險表、量化指標、持倉情緒摘要與整合 AI 報告。
- 提供資產指標 CSV 與持倉情緒 CSV。
- 報告需嵌入繁體中文字型並附教育用途免責聲明。

### U-007 錯誤、安全與效能

- API Key 僅能存在環境變數或 `.streamlit/secrets.toml`，後者必須被 Git 忽略。
- 禁止在 URL、畫面、錯誤訊息或一般應用日誌顯示 Key。
- 外部 API 全部設定逾時並轉換為可操作的使用者訊息。
- Alpha Vantage 免費方案限制可能變動；UI 提醒使用者以帳戶頁面為準並避免重複請求。
- 使用 Streamlit cache，且不得快取或顯示憑證內容。

## 5. 驗收標準

1. 離線模式可從投資組合設定一路產生整合結果，不呼叫外部 API。
2. Live 模式可分別取得 FMP 風險資料與 Alpha Vantage 新聞／價格資料。
3. K 線包含四條指定均線；新聞具有兩套情緒分布與完整明細。
4. 整合頁同時呈現價格風險與多持倉新聞情緒，且沒有不合理地合併量尺。
5. PDF 含風險與情緒兩部分。
6. 單元測試涵蓋邊界、缺值、API 解析、整合加權與提示詞安全。
7. GitHub 不包含真實 API Key、課程講義或未授權原始碼。
